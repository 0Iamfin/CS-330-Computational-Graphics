# CS-330-Computational-Graphics
SNHU CS 330 portfolio showcasing OpenGL, C++, 3D visualization, and interactive graphics.
CS 330 – Computational Graphics and Visualization
3D Scene Project
For my CS 330 final project, I used C++ and OpenGL to build an interactive 3D scene. The finished scene includes a stacked pyramid sculpture on a brick pedestal, two decorative columns topped with spheres, and a textured ground plane. I used pyramid, box, cylinder, sphere, and plane meshes to construct the objects. I also added stone, brick, and metal textures, lighting, and controls that let a user explore the scene from different angles.

Project artifacts:
- The 3D Scene ZIP file, including source code and the Visual Studio project
- The Design Decisions Word document describing my design and development choices
Camera controls: W/A/S/D to move forward, left, backward, and right; Q/E to move vertically; mouse to look around; mouse wheel to adjust movement speed; P for perspective view; O for orthographic view.
Reflection
How do I approach designing software?
This project helped me understand how much planning goes into creating a scene that looks organized and makes sense to the user. I started with simple geometric shapes and thought about how to scale, rotate, and position each one using the X, Y, and Z axes. From there, I added textures and lighting to improve the appearance. I also learned that it helps to work on one feature at a time instead of trying to complete everything at once. I can use this same approach in future projects by identifying what the user needs, planning the design, and testing each part before moving forward.
How do I approach developing programs?
When developing the scene, I built on what I completed in each milestone. I worked with reusable meshes and functions for transformations, textures, materials, and lighting. I tested my changes in Visual Studio, adjusted the object placement, and corrected the camera controls so I could switch between perspective and orthographic views. One thing I learned was that making small changes and running the program often makes it easier to find mistakes. My approach to programming has become more organized because I now pay closer attention to breaking down problems, reusing code, and checking that everything works together.
How can computer science help me in reaching my goals?
Computer graphics has given me a better understanding of how programming can turn basic shapes and mathematical coordinates into interactive environments. These skills will help me as I continue working toward my computer science degree because they strengthen my understanding of C++, problem-solving, and application development. Professionally, I can apply what I learned about planning, testing, modular code, and user interaction to software engineering projects. Even if I work outside of graphics, the development process I practiced in this course will still be useful.
